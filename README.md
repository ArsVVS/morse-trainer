# Азбука Морзе – тренажёр (MorseTrainer)

Учебное приложение для Windows: переводчик текста в код Морзе и обратно и тренажёр приёма и передачи.
Код показывается картинкой, миганием лампы и звуком, при воспроизведении подсвечивается текущая буква.
Тренажёр работает по методу Коха, ведёт статистику и умеет принимать передачу «ключом» – клавишей пробела.
Есть консольная утилита и демонстрационный ноутбук.

## Возможности

- перевод текста в код и обратно «на лету», предупреждения о неизвестных символах;
- латиница, кириллица, цифры и основные знаки препинания; похожие символы (`·`, `•`, `_`, `–`, `—`) понимаются как точка и тире;
- три варианта вывода: картинка (сохранение в SVG и PNG), мерцание лампы, звук (сохранение в WAV);
- звук и свет синхронны, скорость (5–40 WPM) и частота тона меняются прямо на вкладке;
- тренажёр: приём и передача, ввод точками и тире или ключом, уровни по методу Коха;
- задания: отдельные символы, группы по 5 символов или слова; итоги сессии и переход на следующий уровень при точности от 90%;
- статистика: график точности по дням, последние сессии, проблемные символы, текущие уровни;
- справочник алфавита с воспроизведением символа по клику;
- светлая и тёмная тема, горячие клавиши, справка по F1;
- консольная утилита `morse` для перевода, сохранения WAV и SVG, воспроизведения и тренировки.

Используемые библиотеки: CommunityToolkit.Mvvm, NAudio (воспроизведение звука), ScottPlot (график статистики),
System.CommandLine, xUnit. WAV и SVG генерируются в библиотеке `MorseTrainer.Core` без сторонних пакетов.

## Запуск

```
dotnet build
dotnet test
```

Запуск графического приложения:

```
dotnet run --project src/MorseTrainer.Wpf
```

Консольная утилита:

```
morse encode "SOS help"                                   # текст → код
morse decode "... --- ... / .... . .-.. .--."             # код → текст
morse encode "привет" --alphabet cyr
morse encode "CQ CQ" --wav cq.wav [--wpm 20] [--freq 700] # сохранить звук
morse encode "CQ CQ" --svg cq.svg                         # сохранить картинку
morse play "SOS" [--wpm 15]                               # проиграть звук
morse train --mode receive [--level 3] [--count 10]       # тренировка приёма
morse train --mode send [--level 3] [--count 10]          # тренировка передачи
morse stats                                               # краткая статистика
```

Демонстрация работы библиотеки – в ноутбуке `showcase/morse-showcase.ipynb` (перед запуском нужен `dotnet build`).

Настройки хранятся в `%APPDATA%\MorseTrainer\settings.json`, статистика – в `%APPDATA%\MorseTrainer\stats.json`.
